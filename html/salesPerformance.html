01 — PROJECT OVERVIEW

About the Project

The Sales Performance Dashboard is a data analytics project focused on presenting sales information in an interactive and visually understandable format.

The dashboard converts structured sales data into charts, key performance indicators and visual summaries that make it easier to identify patterns and understand overall sales performance.

The project demonstrates the use of spreadsheet analysis and business intelligence tools for organizing, analyzing and presenting business data.
